# Estudos

| Pasta | O que é |
|---|---|
| [`tecnicas_de_treinamento_2025/`](tecnicas_de_treinamento_2025/) | Grid search contra um ensemble guiado pela curva de viés e variância, modelo único contra modelos por segmento, e o efeito do tamanho da amostra, com uma base oculta para a avaliação final (Telco Customer Churn, 2025) |
| [`treinamento_personalizado_2025/`](treinamento_personalizado_2025/) | Um otimizador próprio para redes neurais, em que um passo só vale se melhorar todos os subconjuntos do treino. A direção vem de um problema convexo (cvxpy), e o passo, de uma busca linear. Ensemble ponderado, no Titanic, comparado a um CatBoost (2024–2025) |
| [`exportacao_pmml_onnx_2022/`](exportacao_pmml_onnx_2022/) | Como levar árvores, XGBoost e ensembles do Python para PMML e ONNX e conferir que o arquivo exportado dá as mesmas probabilidades (2022) |
| [`neuroevolucao_pygad_2023/`](neuroevolucao_pygad_2023/) | Uma rede neural treinada por algoritmo genético (PyGAD), com a população inteira avaliada numa só chamada na GPU (2023) |

Cada pasta tem um README com o desenho, os resultados e como rodar.
